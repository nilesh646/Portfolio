# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/nilesh646/Portfolio.git
```

Move to project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm start
```

Open:

```text
http://localhost:3000
```
